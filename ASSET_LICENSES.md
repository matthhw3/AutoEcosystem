# Asset provenance

All current terrain, vegetation, rocks, water, animal silhouettes and UI are generated from Godot primitives and project code. No external models, textures, sounds, animations or fonts are bundled. The engine's built-in font is used at runtime. No imported assets and no LFS requirement at initialization.

Future imports require source URL, author, exact license/version, redistribution permission, modifications, attribution text, and a stored license copy before committing. Unclear rights block import, not procedural development. No project software license has been selected.
