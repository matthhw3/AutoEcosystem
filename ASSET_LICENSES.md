# Asset provenance

All current terrain, vegetation, rocks, water, animal models, poses and UI are generated from Godot primitives and project code. Forest wind/bird ambience is synthesized locally from filtered noise and sine waves; no recordings are used. No external models, textures, sounds, animations or fonts are bundled. The engine's built-in font is used at runtime. No imported assets require LFS.

The ignored portable Windows bundle includes the existing Godot engine binary. Its MIT text and component copyright/license information are extracted from the exact binary using Engine license APIs into GODOT_LICENSE.txt and GODOT_THIRD_PARTY.json. These apply to the engine/components, not to this project's original code. Reference: https://docs.godotengine.org/en/stable/about/complying_with_licenses.html. Build binaries are not committed or pushed.

Future imports require source URL, author, exact license/version, redistribution permission, modifications, attribution text, and a stored license copy before committing. Unclear rights block import, not procedural development. No project software license has been selected.
